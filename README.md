# UniSolve

A campus issue reporting and resolution platform.

## About

UniSolve helps students and staff report campus problems, track their progress, and coordinate with maintenance teams to resolve issues efficiently.

## Planned Features

- Report campus issues
- Track issue status in real time
- Assign issues to maintenance staff
- Add comments and updates
- View campus issue statistics

## Technology Stack

- Frontend: React
- Backend: Node.js and Express
- Database: PostgreSQL

## Status

Currently in development.
